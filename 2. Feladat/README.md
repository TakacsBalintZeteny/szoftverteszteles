RÓMAI SZÁM ÁTVÁLTÓ



A projekt egy JavaScript programot tartalmaz, amely arab számokat alakít át római számokká 1 és 3999 között.



FUTTATÁS:



Nyisd meg az index.html fájlt egy böngészőben.

A program automatikusan betöltődik.

A QUnit tesztek automatikusan elindulnak.



TESZTELÉS: A tesztelés a QUnit 2.26.0 keretrendszerrel történik. Összesen 19 teszteset ellenőrzi a számok helyes átváltását. A teszteredmények az oldalon jelennek meg:



Zöld: sikeres teszt.

Piros: sikertelen teszt.



SZÜKSÉGES FÁJLOK:



index.html

qunit-2.26.0.js

qunit-2.26.0.css



A program futtatásához nincs szükség külön telepítésre, elegendő egy modern webböngésző.
